# First-language tip review

The 12 language packs in `src/content/first-language-tips.ts` are draft practice suggestions. Each contains six tips with an example and an existing practice route. They do not assess an individual speaker.

Before release, a knowledgeable speaker must review each pack for accuracy, respect, and useful examples. No language pack has been reviewed yet. The Guides introduction labels them as drafts. Automated checks cover examples, links and wording; they cannot replace this review.
